# Omitted fixtures

`Mac.xml`, `Oth.xml`, `Lr.xml` — Folger TEI XML for *Macbeth*, *Othello*,
*King Lear* — are intentionally **not included**, because they are licensed
CC BY-NC 3.0 (Folger Shakespeare Library) and this repository's code is
AGPL-3.0-licensed. Download them yourself from
<https://www.folgerdigitaltexts.org> and place them here (same filenames) to
run the full parser test suite locally.

See the top-level `NOTICE` for the full attribution and rationale.
